## What is this
SpaceAround is a space exploration game. You are contronling spaceship. Using `LMB` you can accelerate in mouse direction. You can explode planets (White circles), if you crash into them on a certain speed. Planets are placed on a procedurally generated orbits of THE SUN (They are the dark gray circles). If you touch THE SUN, the game will close

## Run game
Windows: run file `executable/space_around_1-0_windows.exe` \
Linux: run file `executable/space_around_1-0_linux`
